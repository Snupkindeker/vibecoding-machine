# 🤖 vibecoding-machine

**vibecoding-machine** — это ИИ-ассистент для программирования, который подключает большую языковую модель (LLM) к реальным инструментам для работы с GitHub. Общайтесь с ним в терминале или в современном веб-интерфейсе (Streamlit) — и он сам спланирует и выполнит многошаговые задачи: создаст репозитории, будет управлять файлами, устанавливать лицензии, искать информацию в интернете и запускать код на 20+ языках программирования.

Ассистент строит своё поведение на основе ваших предпочтений (стиль кода, использование Markdown, предпочитаемые языки), соблюдает правила безопасности (репозитории по умолчанию приватные, без нелегального ПО) и показывает каждый свой шаг.

## ✨ Возможности

- 🧠 **Агент на базе LLM** — использует вызов функций (function calling), чтобы планировать и выполнять многошаговые задачи по одному запросу.
- 💬 **Два интерфейса** — красочный чат в терминале (`terminal.py`) и современный веб-интерфейс (`app.py`, Streamlit).
- 🔧 **Инструменты GitHub** — создание репозиториев, чтение/запись/удаление файлов, просмотр содержимого репозиториев.
- 📜 **Управление лицензиями** — автоматическая установка лицензий MIT, Apache-2.0, GPL-3.0, MPL-2.0 или CC0.
- 🌐 **Поиск в интернете** — встроенный поиск через API Langsearch.
- 🕒 **Инструмент даты и времени** — получение текущей даты и времени в любом часовом поясе.
- 🧪 **Запуск кода** — выполнение кода на 20+ языках (бэкенд Judge0) с выводом stdout/stderr.
- ⚙️ **Настройки на лету** — смена модели, лимитов операций, предпочтений и языка командой `/config`.
- 🌍 **Локализация** — 13 языков интерфейса.
- 🐳 **Поддержка Docker** — образ контейнера и автоматический workflow публикации.

## 🛠️ Как это работает

1. Вы отправляете сообщение из терминала или веб-интерфейса.
2. Ассистент вызывает LLM с системным промптом, сгенерированным на основе ваших настроек в `ai/config.py`.
3. Если модель решает вызвать инструмент, он выполняется, а результат возвращается модели.
4. Цикл повторяется, пока модель не даст финальный ответ (до `model_operation_limit` итераций).

## 📦 Требования

- Python 3.10+ (рекомендуется 3.13; переносимый Python для Windows включён в `python/`)
- Ключ API и endpoint LLM, совместимой с OpenAI
- Ключ API Langsearch для поиска в интернете (опционально, но рекомендуется)

## 🔧 Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Snupkindeker/vibecoding-machine.git
cd vibecoding-machine

# 2. Создайте и активируйте виртуальное окружение (рекомендуется)
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Создайте файл .env со своими ключами
AI_API_KEY=your_llm_api_key
AI_API_ENDPOINT=https://your-llm-endpoint/v1
LANGSEARCH_KEY=your_langsearch_api_key
```

В Windows также можно воспользоваться готовыми скриптами: `run.bat`, `run.ps1` или `start_app.bat`.

## ⚙️ Конфигурация

Основные настройки находятся в [`ai/config.py`](ai/config.py):

| Настройка | Описание | По умолчанию |
| --- | --- | --- |
| `model_name` | Модель LLM для общения | `deepseek-v4-flash-0731` |
| `model_operation_limit` | Максимум вызовов инструментов + шагов размышления на один запрос | `25` |
| `github_username` | Ваш логин на GitHub (нужен для GitHub-инструментов) | `Snupkindeker` |
| `coding_case` | `snake`, `camel` или `pascal` | `snake` |
| `use_markdown` | Использовать ли Markdown в ответах ИИ | `True` |
| `preferred_languages` | Предпочитаемые языки программирования (пусто = любые) | `[]` |
| `language` | Язык интерфейса: `en`, `ru`, `es`, ... | `en` |

## 🚀 Использование

### 💻 Терминальный интерфейс

```bash
python terminal.py
```

### 🌐 Веб-интерфейс (Streamlit)

```bash
streamlit run app.py
```

### 🚀 Запуск обоих одновременно

```bash
python main.py
```

Эта команда запускает приложение Streamlit в фоне, а терминальный чат — в текущем окне. Для выхода нажмите `Ctrl+C` или введите `/stop`.

## ⌨️ Команды

| Команда | Описание |
| --- | --- |
| `/help` | Показать справку |
| `/stop` | Выйти из чата |
| `/wipe` | Очистить историю диалога |
| `/config` | Показать текущую конфигурацию |
| `/config check` | Проверить конфигурацию |
| `/config reset` | Сбросить конфигурацию к значениям по умолчанию |
| `/config <ключ> <значение>` | Изменить отдельную настройку |
| `/save <имя>` | Сохранить текущий диалог |
| `/load <имя>` | Загрузить сохранённый диалог |
| `/del <имя>` | Удалить сохранённый диалог |

Сохранённые диалоги хранятся в виде JSON в папке `ai/dialogs/`.

## 🌍 Локализация

Интерфейс доступен на **13 языках** (`locales/*.json`): английский, русский, испанский, французский, китайский, арабский, немецкий, корейский, португальский, японский, хинди, бенгальский и итальянский.

Сменить язык можно командой `/config language <код>` или через боковую панель веб-приложения.

## 🐳 Docker

Включён [`Dockerfile`](Dockerfile) на базе `python:3.13-slim`, а `.github/workflows/docker-publish.yml` автоматически публикует образ.

```bash
docker build -t vibecoding-machine .
docker run -p 8501:8501 --env-file .env vibecoding-machine
```

Чтобы в контейнере запустить только веб-интерфейс, переопределите команду:

```bash
docker run -p 8501:8501 --env-file .env vibecoding-machine streamlit run app.py --server.port 8501 --server.address 0.0.0.0
```
